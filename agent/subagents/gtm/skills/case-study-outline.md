# Case study outline procedure

Turn a pilot or customer result into a sales-ready case study outline. Do not invent metrics; use placeholders where facts are missing.

## Steps

1. State the case study one-liner: customer type + problem + outcome (placeholders OK).
2. Draft a short outline with these sections, one purpose sentence each:
   - Customer snapshot (who they are, segment, context)
   - Challenge / before state
   - Why they chose the product / approach
   - Implementation / pilot shape
   - Results / after state (quantified placeholders)
   - Quote bank (suggested quote themes)
   - CTA / how a prospect should use this story
3. List 3–5 facts still needed from the customer or founder before publishing.
4. Keep it scannable: headings and short bullets only.
